# ADR-0002: Dateibasiertes kanonisches Modell

Status: Accepted

Entscheidung: MVP 0 und MVP 1 verwenden versionierbare Dateien, stabile prefixed ULIDs und gerichtete typisierte Relationen. Pfade und Titel sind keine Identitaet. Eine Datenbank ist nicht erforderlich.

Konsequenz: Der Vertrag bleibt lokal, transparent und portabel. Suchindizes duerfen spaeter generiert werden, aber nicht zur Source of Truth werden.
