# Projektintake verarbeiten

1. Lies [Vertrag](references/contract.md) und [Safety/Evidence](../_shared/safety-and-evidence.md).
2. Binde Quelle, Revision, Hash, Klassifikation und Sensitivität.
3. Vergleiche ausschließlich gegen einen validierten Workspace-Snapshot.
4. Trenne Beobachtung, Interpretation, Konflikt und Vorschlag.
5. Lege menschliche Reviewentscheidung und Stale-Kriterien fest.
6. Gib niemals automatisch Atlassian-, Workspace- oder Dokumentwrites frei.
