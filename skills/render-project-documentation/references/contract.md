# Vertrag

- Freiheit: mittel; Layout variabel, Eigentumsgrenze strikt.
- Zulässige Writes: neue lokale generated Dateien und Projektionsindex.
- Verboten: authored Dateien erzeugen, ersetzen oder in generated Sektionen mischen.
- Evidence: Blueprintversion, Snapshot, Source-Revisionen, Digest und generatedAt.
- Stop-Codes: `DOCUMENT_PROVENANCE_MISSING`, `DOCUMENT_AUTHORED_CONFLICT`, `DOCUMENT_PATH_UNSAFE`, `DOCUMENT_GRAPH_INVALID`.
- Reset/Rollback: Staging verwerfen; authored Bestand unverändert lassen.
