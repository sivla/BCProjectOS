# Generated Deliverables

Dieser Bereich enthaelt pro Change ein vollstaendiges lokales Delivery-Paket.

```text
deliverables/<change-id>/
|-- tickets/
|-- uat/
|-- documentation/
|-- training/
|-- confluence/
|-- release/
|-- evidence.json
`-- manifest.json
```

Alle Dateien ausser `evidence.json` werden durch den lokalen Generator verwaltet. Eine Generierung ist keine Freigabe und eine vorbereitete UAT ist kein bestandener Test.
