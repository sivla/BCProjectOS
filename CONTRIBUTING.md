# Mitwirken

Änderungen beginnen als genau ein aktiver OpenSpec-Change. Produktwissen bleibt kundenunabhängig; synthetische Fixtures enthalten keine Kunden-, Personen-, Tenant-, Auth- oder Evidence-Daten. Vor Übergabe sind die fokussierten positiven und negativen Tests, Product Contract, OpenSpec strict, `git diff --check` sowie der Marker-/Secret-Scan auszuführen.

Branches, Remotes, Pull Requests, Tags und Releases werden nur nach ausdrücklicher Freigabe verändert. Ein Candidate ist kein veröffentlichter Release.
