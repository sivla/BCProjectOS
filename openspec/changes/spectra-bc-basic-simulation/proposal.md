# Proposal: Spectra Synthetic BC-Basic Simulation

Der nächste Releasezyklus baut auf Spectra 0.1.0-alpha.2 auf und ergänzt ausschließlich eine kundenunabhängige synthetische BC-Basic-Gesamtstrecke. Eine Folgeverversion wird erst nach Gap-/Nutzungsanalyse und bestandener Evidence begründet; dieser Change behauptet keine Version.

Nicht enthalten sind reale BC-Zugriffe, Kundeninhalte, externe Systeme, Project Twin, Datei-Inbox und produktive Integrationen.
