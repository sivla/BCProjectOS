# Synthetischer Kundenworkspace POV-001

Dieser Workspace enthaelt keine echten Kunden-, Personen-, Tenant-, Umgebungs- oder Budgetdaten. Alle Inhalte sind synthetische Pilotartefakte. Freigaben, Testausfuehrungen, UAT, Schulungen und Releases werden nicht behauptet.

BC-Baseline: `knowledge/bc/` enthaelt rudimentaere Navigation fuer Sales, Purchasing, Inventory und Finance. Der fachliche Pilotfall betrifft ausschliesslich Sales; die anderen Bereiche bleiben bewusst leer.
